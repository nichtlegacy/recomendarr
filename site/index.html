Pics How It Works

From diary to recommendations

Content signals and collaborative filtering, with an explanation behind every pick.

  1. Understand the profileRatings, likes and rewatches reveal themes, genres, people and favourite films.
  2. Rank unseen filmsTwo lanes combine collaborative predictions and content matches, with quality filters learned from the profile.
  3. Explain every pickThe interface shows the score components, matching metadata and favourite films behind each recommendation.

Built for private use

A personal application with a public showcase of its interface and method.

  • Private projectI run the recommendation engine privately. This site documents what I built and how it works.
  • Separate storageGenerated recommendation pages live outside this public source repository.
  • Public dataThe engine reads public Letterboxd data. The interface presents recommendations and their explanations.
  • Static interfacePlain HTML and CSS with small interactive scripts, served without cookies or analytics.
